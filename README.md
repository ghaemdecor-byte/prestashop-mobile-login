# ماژول ورود با موبایل برای PrestaShop 1.7

این ماژول به شما امکان می‌دهد که مشتریان خود را با استفاده از شماره موبایل وارد سایت کنید.

## ویژگی‌ها

- ورود و ثبت نام با شماره موبایل
- اعتبارسنجی شماره با پیامک
- امکان استفاده از پنل‌های پیامکی sms.ir و رنگینه
- تنظیمات API Key و Template ID در پنل مدیریت

## نصب

1. ماژول را در پوشه `modules/` فروشگاه خود قرار دهید.
2. از طریق پنل مدیریت PrestaShop، ماژول را نصب و فعال کنید.
3. تنظیمات API را وارد کنید.

## پشتیبانی

در صورت بروز هرگونه مشکل، با ما تماس بگیرید.
